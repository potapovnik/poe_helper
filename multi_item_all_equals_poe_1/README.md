В `target.txt` и `base.txt` укажите по одному свойству на строку. Совпадения из
обоих файлов суммируются: если найдено не меньше `REQUIRED_TARGETS` строк,
скрипт переходит к следующему предмету.

Если найдена хотя бы одна строка из `base.txt` и при этом не найдено ни одной
строки из `not_target.txt`, скрипт выполняет специальную последовательность:
использует валюту из ячейки `191`, возвращается к предмету и проверяет результат.
Если условие перехода не выполнено, пробует валюту из ячейки `71`, затем
продолжает обычный цикл перебросов до `MAX_ATTEMPTS`.

Клики по предметам привязаны к координатам сетки, рассчитанным от позиции
курсора над её верхней левой ячейкой при запуске. Координаты вкладок тайника и
ячеек валюты заданы для экрана 1919 x 1199. Файлы со списками свойств должны
находиться рядом со скриптом. После кликов по валюте и вкладкам выдерживается
пауза 0.35 секунды; задержка кликов по сетке остаётся `CLICK_DELAY`.
