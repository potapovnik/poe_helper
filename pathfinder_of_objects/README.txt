PoE 2 Target Clicker v2

Установка:
  python -m pip install --upgrade pip setuptools wheel
  pip install -r requirements.txt

Запуск:
  python poe2_target_clicker.py

Первый запуск EasyOCR скачает языковые модели русского и английского языков.

Изменения:
- область поиска по умолчанию рассчитывается пропорционально разрешению экрана;
- OCR увеличивает изображение перед распознаванием;
- сравнение названий строгое: число слов и их порядок должны совпадать;
- «Верстак для разборки» не должен приниматься за «Верстак для перековки»;
- добавлен таргет «Дориани» (команда 3). Пока он только ищется и по нему выполняется клик;
  проверка открытия окна для него отключена, так как эталон интерфейса не предоставлен.

Настройки в начале файла:
- SEARCH_REGION_MODE = "center" — центральная область, адаптивная к разрешению;
- SEARCH_REGION_MODE = "full" — весь экран;
- SEARCH_REGION_MODE = "manual" — вручную заданные координаты;
- MANUAL_SEARCH_REGION — координаты для ручного режима;
- SEARCH_ATTEMPTS — число повторов поиска;
- MAX_CLICK_ATTEMPTS — число попыток клика;
- TEMPLATE_THRESHOLD — порог проверки открытого окна.

Важно:
- Игра должна быть видна на основном мониторе.
- При первом запуске проверь, что распознанная область совпадает с игровым полем.
- Проверка открытия окна зависит от разрешения и масштаба интерфейса игры.
