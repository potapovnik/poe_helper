Программа предназначена для поиска совпадений
в target лежат все варианты характеристик которые нас устраивают
MAX_ATTEMPTS - задаёт кол-во попыток для каждого элемента
REQUIRED_TARGETS - отвечает за то сколько свойств на предмете должно совпасть со списком свойств из target
При этом идёт обход по сетке N x M, где N = COLUMNS - количество столбцов сетки
M = ROWS - 1 количество строк сетки
