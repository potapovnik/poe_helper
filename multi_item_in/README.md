# Поиск хаоса

Главный интерфейс: `search_chaos.py`. Настройки хранятся в `config.json`,
список целевых свойств — в `target.txt`, журналы — в `logs`.

Строки в `target.txt` без символов `.`, `*`, `?` ищутся как обычная
подстрока текста без регулярных выражений. Если присутствует хотя бы один из
этих символов, используется маска: `.` и `*` соответствуют одному символу,
`?` — любому количеству символов. Остальные символы всегда считаются буквальными.

Для альтернативных наборов разделяйте группы пустой строкой:

```text
свойство первой группы 1
свойство первой группы 2

свойство второй группы 1
свойство второй группы 2
свойство второй группы 3
```

В этом режиме предмет подходит, только если найдены все свойства хотя бы одной
группы; число строк в разных группах может отличаться. Без пустой строки
сохраняется прежний режим `TARGET_REQUIRED` / `TARGET_EXACT`.

В целевом свойстве также можно задать числовое сравнение: `>10` означает,
что соответствующее число в тексте должно быть строго больше 10, а `<10` —
строго меньше 10. Например, `броня >10%` совпадёт со строкой `броня 12%`,
но не со строкой `броня 8%`. Сравнения можно использовать внутри любой группы.

Для сборки Windows-приложения установите PyInstaller и запустите:

```powershell
python -m pip install pyinstaller
python build_search_chaos.py
```

Сборка появится в `build_output/search_chaos`: запускаемый файл
`search_chaos.exe`, правила в `rule`, журналы в `Log`, а настройки рядом с exe.
Сборка включает `background.png`; изображение используется только в верхней
шапке интерфейса.
