Программа предназначена для поиска совпадений
в target лежат все варианты характеристик которые нас устраивают
MAX_ATTEMPTS - задаёт кол-во попыток для каждого элемента
TARGET_MODE - отвечает за способ совпадения:
ANY - совпадает с одним любым значением из target
ALL - совпадает со всем значениями из target
